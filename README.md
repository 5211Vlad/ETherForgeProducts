## Research

Public research pages describe **GhostOS**, **MAGI**, **METRON**, **Avalon**, and embodied/fabrication systems only at the capability/objective level. EtherForge does not use this repository to publish private architecture, credentials, unreleased CAD, proprietary formulas, or unsupported AGI/sentience claims.

Research themes include provider-independent continuity, provenance-bound memory, evidence-governed multi-perspective analysis, context efficiency, bounded agent execution, robotics, and fabrication tooling.
