WHEN “SEND ME THE PROJECT” ISN'T ENOUGH

Give the next person something they can inspect.

Handoff Forge is for client delivery, project transfer, continuity checkpoints, and the uncomfortable moment when future-you becomes the next maintainer.

01 · ACCOUNT

Know what is actually in the folder.

Build a deterministic inventory with file sizes and hashes where supported, so the handoff has a concrete reference point.

02 · EXPLAIN

Add readable context.

Generate a Markdown handoff around the folder plus a CSV manifest for machine-readable inspection and archival.

03 · VERIFY

Preserve evidence without pretending it understands the project.

Hashes and manifests prove file identity. They do not explain architecture, replace source control, or invent missing human decisions.
